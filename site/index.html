How it works

1

Install

One small download. On Windows it installs just for you, no admin prompt, and fetches anything missing by itself. On Linux, the .deb and .rpm set up touchpad access for you.

2

Follow the setup

A one-minute tutorial checks your touchpad, switches off the OS gestures that would clash, and gives you a starter set: Recommended, Like a Mac, Media, Productivity or Minimal.

3

Make it yours

Click any gesture and pick what it does. Give apps their own gestures, like swiping between browser tabs only in Chrome. Pady lives in the tray and stays out of the way.

Under the hood

Pady reads every finger straight from the touchpad (Windows Precision Touchpad or Linux evdev), measures movement in millimetres so it feels the same on every laptop, and turns it into gestures in well under a millisecond. It's written in Rust, sleeps when you're not touching the pad, has no telemetry, and never needs an account.

FAQ

Is it free?

Yes. Pady is free and open source, with no ads, no accounts and no telemetry.

Windows says "Windows protected your PC"

New apps without a paid code-signing certificate get that warning. Click More info → Run anyway. Every release lists SHA-256 checksums so you can check the file.

Windows still switches apps when I swipe with three fingers

Windows runs its own gestures alongside Pady. Pady's setup shows you exactly which ones to turn off (Settings › Bluetooth & devices › Touchpad), with a button straight to that page. Five-finger gestures never clash.

Which touchpads work?

On Windows, any Precision Touchpad, which is most laptops from the last several years. On Linux, any multitouch touchpad, including ones that track fewer fingers than they report.

Does it work on Wayland?

Gestures and all actions do. Per-app profiles and "switch to app" need to know which window is in front: that works for X11 and XWayland apps, and on KDE Plasma.

How much does it slow my PC down?

It doesn't. In the tray Pady is one process using about 20 MB and no CPU while you're not touching the pad. The settings window uses more while it's open and frees it all when you close it.

Is it safe?

Pady reads only the touchpad, never the keyboard, works entirely offline, and is checked with fuzz tests and dependency audits. The details are in the security notes.
