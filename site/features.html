33 gestures, with 3, 4 or 5 fingers

One finger points and two fingers scroll, like always. Each of these works with three, four or five fingers, and each finger count is its own gesture.

tap

Tap

Touch and lift.

doubletap · tripletap

Double & triple tap

Two or three taps in a row, each its own gesture. Single taps wait a moment only when you've used these.

hold

Hold

Rest your fingers without moving, 0.6 s by default.

swipe · up down left right

Swipe

Four directions. Keep sliding to keep stepping, like scrubbing the volume or flicking through tracks.

pinch · in out

Pinch

Fingers together or apart, with repeats: zoom step by step without lifting.

drag

Drag

The Mac classic. Move windows and select text without pressing down; lift and put your fingers back within a moment to keep going.

3 finger counts×11 gestures each=33 tap, double tap, triple tap, hold, 4 swipes, pinch in, pinch out and drag

Point them at anything

Click a gesture and pick what it does. Every action has a Test button, so you can try it before saving.

Keyboard shortcut

Any combo, like ctrl+shift+t or win+d. Record it straight from your keyboard.

Copy & paste

Pinch three fingers in to copy, spread them to paste, with a glowing "Copied" and "Pasted". Works in every app.

Volume & mute

Exact steps on your speakers or headphones, with Pady's own level pill.

Brightness

Laptop screens and external monitors (DDC/CI), on Windows and Linux.

Media keys

Play / pause, next, previous and stop, for Spotify, YouTube and any player.

Open a link

In your default browser, or in Chrome, Edge, Firefox or Brave.

Launch an app

A program, a path, or a link like ms-settings:.

Switch to an app

Brings it to the front, minimises it if it's already there, and starts it if it isn't running.

Run a command

Anything your shell can run.

Lock the screen

One gesture and you're away.

Ready-made picks

Zoom, task view, show desktop, switch desktops, screenshot, close window, open Chrome or YouTube: one click each.

Different gestures in different apps

A profile changes some gestures while certain apps are in front. Everything else follows All apps.

Detect app

Click Detect app, switch to the app, and Pady writes down its name for you.

Change only what you need

Swipe between browser tabs only in Chrome, or turn a gesture off in a game.

The rest stays

Gestures a profile doesn't change keep doing what they do in All apps.

# a profile for browsers
[[profile]]
name = "Browser"
apps = ["chrome.exe", "msedge.exe", "firefox"]

[[profile.binding]]
trigger = "swipe:4:left"
action = { type = "keys", combo = "ctrl+shift+tab" }

[[profile.binding]]
trigger = "tap:4"
action = { type = "none" }   # off here

Guided setup

Checks your touchpad, shows which of the system's own gestures would clash (with a button straight to that page), and lets you pick a starter set.

Five starter sets

Recommended, Like a Mac, Media, Productivity and Minimal. Pick one, then change anything.

Updates itself

Checks GitHub twice a day and installs only updates signed by Pady. You can turn it off.

Starts with your PC

Lives in the tray. Pause it from there, or let it pause itself while a game runs full screen.

A readable config file

Everything is saved as plain TOML. Edit it by hand if you like; Pady picks up the changes within a couple of seconds.

Made for Linux too

The same app, the same gestures, the same settings window.

Every distro

A .deb for Ubuntu, Debian and Mint, an .rpm for Fedora and openSUSE, and an AppImage for everything else.

X11 and Wayland

Gestures and actions work on both. Per-app profiles follow X11 and XWayland apps, and KDE Plasma.

Permissions, handled

The packages set up touchpad access when installed. With the AppImage, one Fix permissions button does it.

Any multitouch touchpad

Read straight from evdev, including touchpads that track fewer fingers than they report.

A command-line tool, too

pady-cli ships next to the app on Windows and Linux.

pady-cli doctor            # check the config, touchpad, clashing gestures and permissions
pady-cli monitor           # show fingers and gestures live, without running actions
pady-cli run               # run Pady with no window
pady-cli app               # print the app in front, for profiles
pady-cli config preset media
pady-cli action '{ type = "volume", step = 5 }'
pady-cli fix-permissions   # Linux: set up touchpad access

Light, quick and private

  • ~20 MB in the tray
  • 0% CPU while idle
  • < 1 ms to recognise a gesture
  • 0 accounts, ads or tracking

Written in Rust

Reads every finger straight from the touchpad and sleeps when you're not touching it. The settings window frees its memory when you close it.

Reads only the touchpad

Never the keyboard. Nothing about you is sent anywhere; the only connection is the update check, which you can turn off.

Tested hard

About 260 unit tests cover every gesture and the config, and fuzz tests throw random input at every parser.
